eloter tunnel

  1. Install Node.js 24.5 or later from nodejs.org, where your device policy allows it.
  2. Open Terminal in the downloaded companion folder.
  3. Run node bridge.mjs --config "$HOME/Downloads/Harbor-Connection.json". Use the actual path to your private connection file.
  4. Keep Terminal open. Click Connect in the extension.
  5. Reload your website, then use Check browsing IP to verify the exit IP.

If the connection file is missing, obtain it from the project owner through a private channel. Never upload it to GitHub or paste its token into chat.

Scope and limits

This uses a local HTTP proxy over the authenticated Render WebSocket tunnel. It handles regular-profile HTTP/HTTPS web traffic to ports 80 and 443. It is not a system VPN. Incognito, WebRTC/UDP, DNS behavior, and other apps are outside its guarantee; games may use other network paths. Existing connections may persist until a tab is reloaded or Chrome is restarted.

Some websites reject proxy exit IPs. Chrome policies, blocked URLs, extension restrictions and device controls remain in force. If installation or proxy control is blocked, ask your administrator to approve the project.

If the companion stops, new proxied web requests fail rather than switch to a direct route. Click Disconnect to restore Chrome’s underlying proxy settings. The badge indicates proxy configuration, not verified remote tunnel health. Use Check browsing IP to test.

HTTPS stays encrypted between Chrome and the destination. Plain HTTP is visible to the tunnel server. The extension reads no page contents or browsing history, and the tunnel credential stays in your local connection file.
