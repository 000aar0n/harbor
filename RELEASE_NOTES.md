Harbor is a small native WebKit browser for macOS 14 or later, for Apple Silicon and Intel Macs.

Download **Harbor-macOS.zip**, extract it, and open **Harbor.app**. No local compilation or signing command is required. Keep it in your own Downloads folder if you do not have permission to install applications.

The build verifies the app signature both before and after ZIP extraction and checks that the app starts on the build Mac. This is an ad-hoc signed preview, not an Apple Developer ID signed or notarized release. Gatekeeper or management policy may prevent it from running; approval may be required. It does not override management controls.

Features: address/search bar, back/forward, reload, session-only browsing data, and an HTTP CONNECT proxy setting. Supply a proxy server you are authorized to use. No US server, free VPN service, or Urban VPN/Chrome/Firefox extension support is included. The proxy only applies to this browser; it is not a system VPN.
