Harbor 0.2 adds Connect/Disconnect for an authenticated encrypted US browsing tunnel hosted on Render.

Download Harbor-macOS.zip, extract it, and open Harbor.app. Import your private Harbor-Connection.json with Tunnel Setup, then click Connect. The access key is saved in macOS Keychain. Keep the connection file private.

The IP-check page verifies the browsing connection. Failed tunnels block web requests instead of switching to direct browsing. Disconnect explicitly restores direct browsing. Switching connections clears the browsing session.

Requires macOS 14 or later. Supports Apple Silicon and Intel. This is a Harbor browsing tunnel, not a system VPN. One US location is available. Free Render hosting may take time to wake up. The preview is ad-hoc signed and not notarized.
